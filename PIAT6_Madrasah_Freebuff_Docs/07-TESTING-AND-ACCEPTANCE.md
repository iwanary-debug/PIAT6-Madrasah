# Testing dan Acceptance Criteria

## Uji wajib

1.  Login dan dashboard sesuai role.
2.  Kamad MTs tidak dapat mengakses data operasional MA; Kamad MA tidak
    dapat mengakses data MTs.
3.  Pimpinan berwenang dapat melihat ringkasan lintas unit.
4.  CRUD siswa, guru, kelas, mapel, jadwal dan filter bekerja.
5.  Presensi tersimpan dan rekap dihitung benar.
6.  Nilai, bobot, nilai akhir, dan rapor konsisten.
7.  Kenaikan kelas memerlukan keputusan pihak berwenang.
8.  LMS: materi, tugas, pengumpulan, koreksi, umpan balik, publikasi
    nilai.
9.  CBT: bank soal, ujian, peserta, jawaban, penilaian objektif, koreksi
    uraian, publikasi hasil.
10. Kunci jawaban tidak dapat dilihat siswa.
11. Grafik dan laporan sesuai data sumber.
12. Data tetap tersimpan setelah halaman dimuat ulang.
13. UI berfungsi pada desktop dan ponsel.
14. Tidak ada tombol inti tanpa aksi.
15. Data demo ditandai dan tidak tercampur diam-diam dengan data resmi.

Untuk setiap skenario, tandai Lulus, Gagal, atau Belum Terverifikasi.
Jangan mengklaim tes telah dilakukan jika belum dijalankan.
Dokumentasikan masalah, dampak, perbaikan, dan keterbatasan.
