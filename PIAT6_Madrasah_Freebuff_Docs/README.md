# PIAT 6 Madrasah Management System v1.0

Paket dokumen pembangunan aplikasi manajemen akademik MTs dan MA di
Freebuff.com.

## File

-   01-PRD-MADRASAH-MTW-MA.md --- kebutuhan produk.
-   02-MODULES-AND-WORKFLOWS.md --- modul dan alur kerja.
-   03-ROLES-AND-PERMISSIONS.md --- RBAC dan pemisahan akses.
-   04-DATA-MODEL.md --- rancangan data.
-   05-UI-UX-SPECIFICATION.md --- pedoman UI/UX.
-   06-LMS-AND-CBT.md --- spesifikasi LMS dan CBT.
-   07-TESTING-AND-ACCEPTANCE.md --- skenario pengujian.
-   08-FREEBUFF-MASTER-PROMPT.md --- prompt utama.
-   09-FREEBUFF-AUDIT-PROMPT.md --- prompt audit.

Simpan di GitHub dalam folder `docs/`. Buka proyek Freebuff, minta AI
membaca dokumen jika akses repo tersedia, lalu gunakan master prompt.
Jika Freebuff tidak dapat membaca repo, salin isi dokumen dan prompt ke
chat proyek.

Keputusan utama: satu aplikasi untuk MTs dan MA; Kamad masing-masing
hanya mengelola unitnya; pimpinan berwenang dapat melihat lintas unit;
LMS dan CBT termasuk v1.0; gunakan data demo yang saling terhubung;
jangan mengklaim fitur berfungsi sebelum diuji.
