# Spesifikasi UI/UX

Buat tampilan modern, bersih, profesional, mudah digunakan, dan
responsif.

-   Sidebar navigasi sesuai role.
-   Header berisi judul halaman, pencarian/notifikasi bila relevan, dan
    profil.
-   Dashboard dengan kartu KPI, grafik, tabel ringkasan, dan daftar
    tindak lanjut.
-   Tabel mendukung pencarian, filter, pengurutan, dan pagination bila
    diperlukan.
-   Form memiliki label, validasi, dan pesan error.
-   Sediakan loading state, empty state, konfirmasi aksi penting, dan
    notifikasi hasil aksi.
-   Gunakan Bahasa Indonesia.
-   Hindari terlalu banyak warna mencolok dan angka statis pada
    dashboard.
-   Kamad MTs masuk ke dashboard MTs; Kamad MA ke dashboard MA; pimpinan
    berwenang ke dashboard eksekutif; guru/siswa ke dashboard
    masing-masing.
-   Uji desktop, tablet, dan ponsel. Jangan mengandalkan warna saja
    untuk menunjukkan status.
